# Automation Commands

Generated by `scripts/generate_docs.py` from `basalt help` — do not edit by hand.

Every command is available through the `basalt` CLI and the editor's TCP server (127.0.0.1:7420).
See `.claude/skills/basalt-make-game/SKILL.md` for the workflow.

## asset

### `asset.import_model`

Instantiates a glTF model's node hierarchy into the scene.

| Parameter | Type / description |
|-----------|--------------------|
| `parent` | ID or name, optional |
| `path` | string, .gltf/.glb or builtin://Cube |

### `asset.list`

Lists project asset files, optionally filtered by extensions (e.g. ['.lua']).

| Parameter | Type / description |
|-----------|--------------------|
| `extensions` | array of strings |

### `asset.read`

Reads a text asset.

| Parameter | Type / description |
|-----------|--------------------|
| `path` | string |

### `asset.write`

Writes a text asset (script, prefab, scene...) to a project-relative path.

| Parameter | Type / description |
|-----------|--------------------|
| `content` | string |
| `path` | string |

## component

### `component.get`

Returns one component's fields.

| Parameter | Type / description |
|-----------|--------------------|
| `component` | string |
| `entity` | ID or name |

### `component.remove`

Removes a component.

| Parameter | Type / description |
|-----------|--------------------|
| `component` | string |
| `entity` | ID or name |

### `component.set`

Adds the component if missing and sets the given fields (others keep their values).

| Parameter | Type / description |
|-----------|--------------------|
| `component` | string, e.g. 'RigidBody' |
| `data` | object of fields |
| `entity` | ID or name |

### `component.types`

Lists every component type with its fields (for component.add/set).

## entity

### `entity.create`

Creates an entity, optionally with a parent and components ({"Mesh": {...}, ...}).

| Parameter | Type / description |
|-----------|--------------------|
| `components` | object: component name -> fields |
| `name` | string |
| `parent` | entity ID or name |

### `entity.destroy`

Destroys an entity and its children.

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |

### `entity.duplicate`

Duplicates an entity and its children (new IDs).

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |
| `name` | string, optional |

### `entity.get`

Returns an entity with all component data.

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |

### `entity.list`

Lists entities (hierarchy order) with their components; optional name substring / component filter.

| Parameter | Type / description |
|-----------|--------------------|
| `component` | string |
| `nameContains` | string |

### `entity.rename`

Renames an entity.

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |
| `name` | string |

### `entity.set_parent`

Re-parents an entity (parent null = root), keeping its world transform unless keepWorld=false.

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |
| `keepWorld` | bool (default true) |
| `parent` | ID, name or null |

### `entity.transform`

Returns local and world transforms of an entity.

| Parameter | Type / description |
|-----------|--------------------|
| `entity` | ID or name |

## lua

### `lua.exec`

Runs Lua in the playing scene's script state; returns the value of the expression.

| Parameter | Type / description |
|-----------|--------------------|
| `code` | string |

## play

### `play.start`

Starts play mode on a copy of the scene (scripts, physics, audio run).

### `play.step`

Advances play mode by N fixed frames (default dt 1/60) and reports script errors.

| Parameter | Type / description |
|-----------|--------------------|
| `assertNoErrors` | bool: fail the command if any script error occurred |
| `dt` | number, seconds per frame |
| `frames` | integer (default 1) |

### `play.stop`

Stops play mode and restores the edit scene.

## scene

### `scene.get`

Returns the whole open scene as JSON (same format as .bscene files).

### `scene.info`

Summary of the open scene: name, path, entity count, state, unsaved changes.

### `scene.new`

Replaces the open scene with an empty one (with a camera and sun unless empty=true).

| Parameter | Type / description |
|-----------|--------------------|
| `empty` | bool |
| `name` | string |

### `scene.open`

Opens a scene file (project-relative path).

| Parameter | Type / description |
|-----------|--------------------|
| `path` | string |

### `scene.save`

Saves the edit scene (to 'path', or the path it was opened from).

| Parameter | Type / description |
|-----------|--------------------|
| `path` | string, project-relative, optional |

### `scene.settings`

Patches scene-level settings: {Renderer: {...}, Physics: {...}, Name}.

| Parameter | Type / description |
|-----------|--------------------|
| `Name` | string |
| `Physics` | object, e.g. {Gravity: [0,-9.81,0]} |
| `Renderer` | object, e.g. {Exposure, Tonemapper, SSAOEnabled, ShadowDistance} |
